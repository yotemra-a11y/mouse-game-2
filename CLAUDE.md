# \# Game Development Project Guidelines

# 

# \## Context

# We are building an HTML-based clicker game optimized for both mobile and desktop. The core mechanic involves rapidly and continuously clicking/tapping on an on-screen element to keep an action from stopping. All screens are already fully designed.

# 

# \## Workflow

# I will build the game screen by screen. For each step, I will provide:

# 1\. A reference image of the fully designed screen.

# 2\. A specific list of the elements required for that screen.

# 3\. The exact filenames for each element (located in the `ELEMENTS` directory).

# 

# \## Strict Directives

# \- \*\*Language:\*\* If I write to you in Hebrew, ALWAYS reply ONLY in English to prevent terminal display issues.

# \- \*\*No Design/Styling Autonomy:\*\* Do NOT design any elements or game visuals yourself. Implement my designs exactly as shown in the references.

# \- \*\*No Asset Generation:\*\* NEVER generate SVG graphics, CSS shapes, or placeholder images.

# \- \*\*Local Assets Only:\*\* ONLY use the local image assets found in the `ELEMENTS` folder.

# \- \*\*Missing Assets Protocol:\*\* If I instruct you to use a specific file/image and you cannot find it in the directory, you MUST STOP immediately. Do NOT attempt to generate a replacement, do NOT write fallback code, and do NOT proceed. Stop the process and ask me for the missing file or correct path.
